#  Micro-Planner

An AI-powered web app that breaks down any overwhelming task into frictionless, 5-minute actionable micro-goals with built-in countdown timers and daily streak tracking.

##  Features
- **AI Task Decomposition:** Instantly breaks tasks into logical, easy-to-hard 5-minute steps.
- **Interactive Timers:** Built-in per-goal countdown timers to maintain hyper-focus.
- **Streak Tracker:** Keeps you motivated by counting completed daily plans.
- **Zero Configuration (Static HTML):** Ready to deploy anywhere instantly.

## 🛠️ Setup & Deployment
1. Open `index.html` and paste your Groq API key into `EMBEDDED_API_KEY`.
2. Push to your GitHub repository.
3. Enable **GitHub Pages** in your repository settings (`Settings > Pages > Branch: main`).
